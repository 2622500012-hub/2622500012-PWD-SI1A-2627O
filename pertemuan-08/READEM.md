# TOKO SEPATU STELLA
# Deskripsi Website
Toko Sepatu Stella merupakan website bisnis yang bergerak di bidang penjualan berbagai jenis sepatu. Website ini dibuat untuk memberikan informasi mengenai produk sepatu, profil pemilik usaha, serta menyediakan formulir registrasi bagi pengunjung.
Website ini menggunakan HTML, CSS, JavaScript, dan PHP dalam proses pembuatannya.
# Identitas Usaha
- **Nama Usaha:** Toko Sepatu Stella
- **Tagline:** Step Into Your Style
- **Jenis Usaha:** Penjualan Sepatu
- **Nama Pemilik:** Stella Lindi Adeviani
# Struktur Website
Website Toko Sepatu Stella terdiri dari beberapa bagian:
# Header
Bagian header menampilkan logo dan nama Toko Sepatu Stella sebagai identitas website.
# Navigasi
Bagian navigasi menggunakan daftar menu yang terdiri dari:
- Home
- Profile
- Registrasi
# Home
Halaman Home menampilkan gambar beberapa produk sepatu serta deskripsi singkat mengenai usaha Toko Sepatu Stella.
# Profile
Halaman Profile menampilkan foto dan biodata pemilik usaha.
# Registrasi
Halaman Registrasi menyediakan formulir untuk memasukkan data pengunjung, seperti nama lengkap, email, nomor telepon, alamat, jenis kelamin, dan password.
# Footer
Bagian footer menampilkan informasi identitas pembuat website sesuai ketentuan tugas.
# Teknologi yang Digunakan
- **HTML:** Digunakan untuk membuat struktur dan elemen halaman website.
- **CSS:** Digunakan untuk mengatur desain, warna, ukuran, jarak, dan tata letak website.
- **JavaScript:** Digunakan untuk mengatur interaksi menu navigasi dan validasi formulir.
- **PHP:** Digunakan untuk mengolah data dan menampilkan informasi secara dinamis.
# Fitur dan Pengembangan
1. **Halaman Home:** Menampilkan informasi usaha dan gambar produk sepatu.
2. **Halaman Profile:** Menampilkan foto dan biodata pemilik usaha.
3. **Halaman Registrasi:** Menyediakan formulir untuk memasukkan data pengunjung.
4. **Navigasi Website:** Memungkinkan pengunjung berpindah antara halaman Home, Profile, dan Registrasi.
5. **Validasi Formulir:** Memeriksa kelengkapan dan kesesuaian data sebelum formulir dikirim.
6. **Tampilan Responsif:** Mengatur tampilan website agar dapat menyesuaikan ukuran layar perangkat.
# Pengujian
Pengujian dilakukan untuk memastikan setiap bagian website dapat berfungsi sesuai kebutuhan.
- Menguji tampilan logo dan nama usaha pada header.
- Menguji menu navigasi Home, Profile, dan Registrasi.
- Menguji tampilan gambar produk sepatu.
- Menguji tampilan foto dan biodata pemilik.
- Menguji formulir registrasi dengan data kosong dan data terisi.
- Menguji validasi JavaScript.
- Menguji proses penerimaan data menggunakan PHP.
