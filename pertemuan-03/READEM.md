## Implementasi Formulir

- Atribut validasi yang digunakan: name, id, for, action, method, placeholder, required, min, max, minlength, dan maxlength 

## Pengujian GET dan POST 

- Hasil pengujian GET: data formulir ditambahkan ke URL dalam bentuk parameter name=value. 
- Contoh URL encoding yang ditemukan: https://2622500012-hub.github.io/2622500012-PWD-SI1A-2627O/pertemuan-03/index.html?nama=Stella+Lindi+Adeviani&email=2622500012%40mahasiswa.atmaluhur.ac.id&semester=1&tanggal=2026-10-05&jenis_pesan=pertanyaan&minat=CSS&prodi=SI&pesan=terus+belajar 
- Hasil pengujian POST: Data POST tidak muncul sebagai query string pada URL. 

## CSS Dasar 

- Selector elemen: Selector elemen digunakan berdasarkan nama tag HTML.
Contoh:
        label {
            ...
        } 
        Selector tersebut digunakan untuk memberikan styling pada elemen <label>.
- Selector class: Selector class digunakan berdasarkan atribut class.
Contoh:
        .input-form {
            ...
        }
        Selector tersebut digunakan pada elemen yang memiliki class input-form. 
- Selector ID: Selector ID digunakan berdasarkan atribut id.
        Contoh:
        #contact {
            ...
        }
        Selector tersebut digunakan untuk memberikan styling pada bagian formulir dengan ID contact.
- Properti CSS dasar yang digunakan: CSS dasar pada P3 menggunakan properti untuk mengatur tampilan, seperti: color, background-color, font, margin, padding, dan border.
CSS digunakan untuk membuat tampilan formulir lebih konsisten, tertata, dan mudah dibaca.
