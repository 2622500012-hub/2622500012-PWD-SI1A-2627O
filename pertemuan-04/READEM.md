# pertemuan-04 - CSS3 Layout dan Responsive Web Design 

## Pengembangan 

- Perubahan yang dilakukan:
    1. Memisahkan CSS dari index.html ke dalam style.css. 
    2. Menerapkan CSS Box Model pada elemen halaman. 
    3. Menerapkan Flexbox untuk penataan navigasi. 
    4. Menerapkan CSS Grid untuk tata letak utama halaman. 
    5. Menerapkan desain web responsif menggunakan media query dengan pendekatan mobile-first. 
    6. Menyesuaikan tata letak dan navigasi agar tetap berfungsi dan mudah digunakan pada perangkat bergerak dan desktop. 
    7. Tidak menggunakan framework CSS.

## Pengujian 

- Perangkat bergerak: ukuran lebar viewport kurang dari 768px sehingga tampilan navigasi beranda, tentang dan kontak tersusun secara vertikal dan bagian home, tentang saya, dan kontact tersusun dalam satu kolom.
- Desktop: ukuran lebar viewport 768px atau lebih dari 768px sehingga tampilan navigasi beranda, tentang dan kontak tersusun secara horizontal dan bagian home, tentang saya, dan kontact tersusun dalam 2 kolom. 
- Galat dan perbaikan: Warna dan tata letak footer awalnya tidak sesuai dengan desain karena aturan CSS footer belum ditambahkan. Masalah diperbaiki dengan menambahkan aturan background-color, color, text-align, padding, margin-top, dan border pada elemen footer, serta mengatur margin paragraf di dalam footer.
